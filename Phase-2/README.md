# Phase-2: Hackathon Dataset Evaluation

## Objective
Evaluate Phase-1 trained model on unseen hackathon dataset.

## Constraints
- No retraining allowed
- Particle class mapped to Others

## Results
Accuracy  : 42.9%
Precision : 48.1%
Recall    : 49.0%

## Observations
- Structured defects (LER, Vias) generalize better.
- Smooth texture classes (Clean, CMP) show confusion.
- Performance drop due to domain shift.
